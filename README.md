# 语涵学习助手 ✨

一个专为八年级学生设计的互动式学习计划管理网页应用，基于李语涵的作息学习打卡表开发。

## 🌟 功能特点

### 1. **智能任务管理**
- 根据星期几自动显示对应的学习计划
- 周一至周五：校内作业 + 英语/语文专项
- 周六：理化空中课堂 + 数学补习 + 周末作业
- 周日：美术课 + 英语一对一补习 + 语文练习

### 2. **游戏化激励系统**
- **学习币奖励**：每完成一个任务获得10学习币
- **连续打卡**：记录连续学习天数
- **娱乐奖励**：用学习币兑换音乐、笑话、表情包、小游戏
- **粒子效果**：完成任务时有炫酷的动画效果

### 3. **个性化定制**
- 自定义计划名称
- 调整每日奖励数量
- 选择提醒音效
- 更换主题颜色
- 所有设置自动保存

### 4. **现代UI设计**
- 响应式设计，支持手机和电脑
- 暗色模式自动适配
- 流畅的动画和过渡效果
- 符合八年级学生审美的配色

## 📱 使用方式

### 方法一：直接打开（推荐）
1. 双击 `index.html` 文件
2. 在浏览器中打开使用
3. 支持 Chrome、Edge、Safari 等现代浏览器

### 方法二：部署到服务器
1. 将整个文件夹上传到网站空间
2. 通过网址访问
3. 支持微信内打开（可作为小程序替代方案）

### 方法三：本地开发
1. 安装 Live Server 等本地服务器插件
2. 右键 `index.html` → "Open with Live Server"
3. 在 `http://localhost:5500` 访问

## 🔧 自定义修改

### 修改任务内容
编辑 `script.js` 文件中的 `taskData` 对象：
```javascript
const taskData = {
    weekday: [...],    // 工作日任务
    saturday: [...],   // 周六任务  
    sunday: [...]      // 周日任务
};
```

### 修改激励语
编辑 `script.js` 中的 `motivationPhrases` 数组：
```javascript
const motivationPhrases = [
    "你的激励语1",
    "你的激励语2",
    // ...
];
```

### 修改奖励内容
编辑 `script.js` 中的 `rewards` 对象：
```javascript
const rewards = {
    music: { ... },
    joke: { ... },
    // ...
};
```

## 📊 数据管理

```javascript
exportPlan();
```

### 重置数据
在浏览器控制台执行：
```javascript
debugReset();
```

- 浏览器 LocalStorage
- 键名：`studyPlanData`
- 格式：JSON

## 🎨 设计理念

### 用户体验
1. **简单直观**：一键完成任务，无需复杂操作
2. **即时反馈**：完成任务立即有视觉和听觉反馈
3. **成就感**：进度条、学习币、连续打卡多重激励
4. **个性化**：颜色、音效、名称都可自定义

### 教育价值
1. **时间管理**：帮助学生建立规律作息
2. **目标导向**：将大目标分解为小任务
3. **自我激励**：通过奖励系统培养内在动力
4. **习惯养成**：连续打卡机制促进坚持

## 🐛 故障排除

### 常见问题
1. **音效不播放**：检查浏览器是否允许自动播放
2. **数据丢失**：检查浏览器是否清除了缓存
3. **布局错乱**：更新到最新版浏览器
4. **动画卡顿**：关闭其他占用资源的标签页

### 调试工具
- 按 F12 打开开发者工具
- 查看 Console 面板的错误信息
- 在 Application 面板查看 LocalStorage
