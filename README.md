# 语涵的学习搭子 - 个性化学习计划管理

## 功能亮点

### 🗓️ 日历式任务管理
- **按周视图**：周一至周日独立任务列表
- **自由编辑**：点击右上角“+添加”创建新任务
- **任务属性**：名称、时间、标签（语文/数学/英语等）、图标
- **实时修改**：点击任务右侧铅笔图标编辑

### ✅ 完成与激励
- **点击完成**：勾选任务即完成，获得8个学习币
- **进度条**：直观显示今日完成百分比
- **连续天数**：记录坚持打卡的连续天数
- **学习币系统**：完成任务获得，用于兑换奖励

### 🎁 奖励兑换
- **吃瓜时间** (5币)：校园笑话/冷知识/毒鸡汤/今日瓜田
- **解压游戏** (10币)：4种小游戏（记忆翻牌/打地鼠/速算挑战/戳泡泡）
- **解锁新主题** (30币)：随机解锁新配色主题
- **搭子抱抱** (0币)：搭子的暖心鼓励

### 🫂 搭子关怀系统
- **健康提醒**：每10分钟提醒喝水/休息/洗头/护眼等
- **搭子对话**：点击搭子头像获得随机鼓励/吐槽
- **个性化搭子**：自定义搭子昵称和形象
- **暖心鼓励**：随机发送14岁学生能共鸣的关怀话语

### 🎮 四大解压游戏
1. **记忆翻牌** (🃏)：找出相同配对的卡片，考验记忆力
2. **打地鼠** (🔨)：打中冒出来的地鼠，避开炸弹
3. **速算挑战** (🧮)：限时心算答题，锻炼反应力
4. **戳泡泡** (🫧)：疯狂戳泡泡，简单解压

### 🎨 个性化设置
- **计划名称**：自定义应用标题
- **搭子昵称**：给你的学习伙伴起名
- **搭子形象**：选择喜欢的动物表情
- **主题色**：从已解锁的颜色中选择

### 📱 PWA 支持
- **添加到手机桌面**：支持安装为独立APP
- **离线可用**：数据本地存储，无需网络
- **全屏体验**：无浏览器界面干扰

## 使用说明

1. **查看任务**：点击顶部的日期卡片切换不同日期
2. **完成任务**：点击任务右侧的圆圈勾选
3. **添加任务**：点击右上角“+添加”按钮
4. **编辑任务**：点击任务右侧的铅笔图标
5. **兑换奖励**：使用学习币在底部兑换区兑换
6. **个性化设置**：点击左下角齿轮图标

## 技术特点

- **纯前端**：单HTML文件，无需后端
- **本地存储**：所有数据保存在浏览器localStorage
- **响应式设计**：适配手机、平板、电脑
- **PWA**：支持安装到手机桌面
- **暗色模式**：自动跟随系统主题

## 部署方式

### 1. GitHub Pages（推荐）
- 将文件上传到GitHub仓库
- 开启GitHub Pages功能
- 通过 https://your-username.github.io/yuhanplan 访问

### 2. 微信小程序（需二次开发）
- 使用微信小程序框架重写
- 申请小程序账号并提交审核
- 适合在微信内分享使用

### 3. 手机安装（PWA）
- 用手机浏览器打开应用
- 点击“添加到主屏幕”
- 像原生APP一样使用
